# CarShopSPa — Номын 2.1–2.13 бүлгийн SPA demo

## Шинэчилсэн 2.10–2.13
- **2.10:** Нүүр хуудасны тайлбар, хотын зарын тоотой интерактив *схем* (`locationMap.js`, `locationService.js`). Газрын жинхэнэ зураг биш.
- **2.11:** Лизингийн аннуитет тооцооны тусдаа service, дэлгэрэнгүй хүснэгт (`loanService.js`, `calculationTable.js`, `calculationInfo.js`).
- **2.12:** Худалдан авах зөвлөмжийн картууд, дэлгэрэнгүй modal (`guidesPage.js`, `guideService.js`, `guides.json`). Өмнөх **зар нэмэх** хуудас хэвээр үлдсэн.
- **2.13:** Footer-д түргэн холбоос, төслийн мэдээлэл, дээш буцах хэсэг нэмсэн.

### Ажиллуулах
`src/index.html`-ийг VS Code Live Server-ээр нээнэ. `fetch` ашиглаж байгаа тул `file://` замаар нээхгүй.

### GitHub Pages
`docs/` нь `src/`-ийн copy. `Settings → Pages → master → /docs` сонгоно.

### Sass
Одоо байгаа хөрвүүлсэн CSS-ийг ашиглана. SCSS өөрчлөх бол `npm install` дараа нь `npm run build:css`, дараа нь `src/.`-г `docs/`-д хуулна.

**Тайлбар:** Зөвхөн сургалтын demo. Зарууд localStorage-д хадгалагддаг; бодит төлбөр, зээл, бүртгэл байхгүй. Номын PDF файлд 2.10–2.13 бүлгийн агуулгын жагсаалт байгаа боловч дэлгэрэнгүй эх код харагдахгүй тул тухайн бүлгийн бүтэц, сэдвээр автомашины хувилбарыг боловсруулав.
